Workflow and Agent Roles

The ecosystem operates as a loop:

Brainstorm / Research / Validate
  -> Keep / Library
  -> Plan / Execute
  -> Store results back into Library

Layers:

- Brainstorm / Research / Validation: BIVA, Thomas
  Purpose: Explore ideas, validate business value, create learning material.

- Keep / Library: KIM
  Purpose: Store, retrieve, summarize, and preserve shared knowledge.

- Planning / Execution: Atlas, Aegis candidate, future execution agents
  Purpose: Turn validated knowledge into plans and implementation.

- Future Design Team: TBD
  Purpose: UX, UI, design systems, brand, prototypes.

Operating Rule:

Need to validate business value? Use BIVA.
Need to learn or research? Use Thomas.
Need to remember or retrieve? Use KIM.
Need to map the project? Use Atlas.
Need to engineer and execute? Use Aegis or execution team, after validation.
Need design? Use future design team.
