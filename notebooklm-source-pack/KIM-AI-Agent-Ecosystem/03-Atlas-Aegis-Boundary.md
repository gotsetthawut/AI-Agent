# Atlas and Aegis Boundary

Atlas and Aegis are separate agent concepts.

## Atlas

Atlas is the Project Cartographer.

Atlas maps:

- Goals
- Phases
- Dependencies
- Decisions
- Agent handoffs
- What should be stored in KIM

Atlas should not become the engineering lead.

## Aegis

Aegis is a candidate Engineering Lead Agent.

Aegis may handle:

- Engineering architecture
- Technical planning
- Code review
- DevOps strategy
- Security review
- QA strategy
- Engineering team supervision

Aegis should be validated by BIVA before becoming a live agent or receiving a
dedicated repo.
