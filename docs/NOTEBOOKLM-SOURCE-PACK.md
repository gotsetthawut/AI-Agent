- The AI-Agent ecosystem
- BIVA, KIM, Thomas, Atlas, and Aegis
- The research and validation workflow
- KIM as the library layer
- NotebookLM as the synthesis layer

## NotebookLM Setup

1. Open NotebookLM.
2. Create a notebook named:

```text
KIM - AI Agent Ecosystem
```

3. Add the source-pack files from Google Drive.
4. Ask the first prompt from `NOTEBOOKLM-PROMPTS.md`.
5. Save useful outputs back into KIM.

Drive source links created from this pack are tracked in:

```text
docs/NOTEBOOKLM-DRIVE-SOURCES.md
```
